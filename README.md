# 🎁 Gift Website

A modern and responsive online gift shopping website designed to help users find and purchase gifts for different occasions.

## 🌟 Project Overview

The Gift Website provides a simple and attractive shopping experience where users can browse gifts based on different occasions such as:

- 🎂 Birthday
- 💍 Anniversary
- ❤️ Valentine's Day
- 💒 Marriage
- 🎉 Puberty / Coming of Age
- 🎁 Other Special Occasions

Users can explore products, add gifts to the cart, login/register, checkout, and place orders.
